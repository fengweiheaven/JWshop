库存汇总工具使用说明

一、如何打开

1. 先解压 InventoryTool.zip。
2. 打开解压后的 InventoryTool 文件夹。
3. 双击 index.html。
4. 系统会用默认浏览器打开库存汇总工具。

注意：
- 不需要联网。
- 不需要安装 Python 或其他软件。
- 不要把 index.html 单独拿出来使用，需要保持 vendor 文件夹、app.js、styles.css 和 index.html 在同一个工具文件夹里。
- 所有数据都在本机浏览器里处理，不会上传到网络。


二、如何新建店铺和商品

1. 在页面顶部的“店铺”区域，点击右侧的“+”按钮。
2. 在弹窗里填写店铺名称。
3. 点击“添加商品”，填写商品名称。
4. 如需计算库存价值，可以在商品后面填写单价。
5. 如表格里的商品名不固定，可以在“匹配关键词/别名”里填写关键词，多个关键词用逗号分隔。
6. 一个店铺可以添加多个商品。
7. 填完后点击“保存”。

商品关键词示例：
如果店铺商品叫“大窑橙汁”，表格里可能写“大窑橙味”“大窑汽水”，就可以把“大窑橙味，大窑汽水”填到该商品的匹配关键词里。上传数据后，只要表格商品名命中这些关键词，就会统计到“大窑橙汁”下面。

修改店铺或商品：
1. 在对应店铺卡片右上角点击“修改”。
2. 可以修改店铺名称、商品名称、商品单价、商品匹配关键词。
3. 点击商品行右侧的“-”可以删除该商品。
4. 点击“保存”后生效。

删除店铺：
1. 点击店铺卡片右上角“修改”。
2. 点击“删除店铺”。
3. 在确认弹窗中点击“确认删除”。


三、如何上传数据

1. 在“数据源文件”区域点击“选择 Excel 或 CSV”。
2. 选择库存表格文件，支持 .xlsx、.xlsm、.csv。
3. 可以只选一个文件，也可以按住 Ctrl 或 Shift 一次选择多个文件。
4. 也可以把一张或多张表直接拖到上传区域。
5. 上传后系统会自动读取表格数据；多张表会合并到同一次统计里。
6. 工具会默认选择当天日期的数据。
7. 如需查看其他日期，可以在“处理日期”下拉框里手动切换。

多表统计说明：
- 每个文件会单独识别表头和列名。
- 同一天、同商品的数据会累加统计。
- 如果某个文件读取失败，其他能读取的文件仍然会参与统计，失败原因会显示在页面提示里。
- 成功上传后的数据会保存在本机浏览器里，刷新页面后会自动恢复；再次上传表格会追加到当前数据源，删除表时才会移除对应数据。
- “数据源表”区域会列出已上传的每张表；点击“新增表”可以继续追加表格，点击表后面的“-”可以只删除该表。

更新新包说明：
- 新包会继续读取本机浏览器里已保存的店铺信息和上次成功上传的数据。
- 只要还是同一台电脑、同一个浏览器，并且没有清理浏览器本地数据，就不需要重新创建店铺或重新导入表格。
- 新包打开时只会读取旧数据，不会主动清空或覆盖旧数据；只有新增表或删除表时，才会改变当前数据源。

表格支持：
- 有“整件数量、单瓶数量、箱规”的库存表。
- 只有“剩余库存/库存数量”的库存表；如果没有箱规，普通商品行按整件统计，商品名带“/瓶”的行按单瓶统计。
- 出库相关列支持识别“出库、出货、调拨、报损、补货、夜补”等。
- 退货相关列支持识别“客退数量、多货退货、多货实退”等。

上传成功后可以看到：
- 店铺下方每个在售商品的库存数量。
- 整件数量、单瓶数量、库存价值。
- “全部商品”模式下，库存价值会把所有能匹配到单价的商品价值加总显示。
- 较前日变化。
- 出库拆分：整件出库、单瓶出库。
- 退货拆分：客退整件/单瓶、多货退货整件/单瓶。

导出库存：
1. 上传数据后，点击店铺区域顶部的“导出库存 TXT”。
2. 会导出所有店铺在售商品的库存文本。
3. 导出格式为：

店铺名
商品名：库存整件xxx，库存单瓶xxx

店铺名
商品名：库存整件xxx，库存单瓶xxx
