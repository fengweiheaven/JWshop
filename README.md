# 库存汇总工具

纯前端离线网页版小工具，支持一次上传一个或多个 `.xlsx`、`.xlsm`、`.csv`，按日期筛选后按商品名称汇总库存。

## 直接使用

Windows 或 Mac 都可以直接打开：

```text
index.html
```

不需要联网，不需要安装 Python，也不需要启动本地服务。Excel 解析库已经放在 `vendor/xlsx.full.min.js`。

## 发给其他电脑

双击 `build_web_offline.bat` 可生成干净的离线发布文件夹：

```text
dist-web\InventoryTool
```

把整个 `InventoryTool` 文件夹复制给 Windows 或 Mac 用户，对方打开里面的 `index.html` 即可使用。

## 上传数据

点击上传区域可以选择单个文件，也可以按住 Ctrl 或 Shift 一次选择多个文件；拖拽上传时也可以同时拖入多张表。工具会分别识别每个文件的表头和数据列，再把所有读取到的明细行合并统计。同一天、同商品的数据会累加到一起。

成功解析后的数据会保存在本机浏览器里，刷新页面后自动恢复；再次上传表格会追加到当前数据源，删除表时才会移除对应数据。

“数据源表”区域会列出当前已上传的每张表。点击“新增表”可以继续追加表格，点击每张表后的 `-` 可以只删除该表，统计结果会按剩余表即时重算并保存。

## 更新新包

店铺信息和上次成功上传的数据都保存在本机浏览器的固定本地存储中，新版本继续沿用同一套数据键。使用新包时，只要还是同一台电脑、同一个浏览器，并且没有清理浏览器本地数据，之前创建的店铺和上传的数据会自动恢复，不需要重新创建店铺或重新导入表格。

## 当前识别列

- 日期：日期、时间、业务日期、单据日期、库存日期、统计日期等
- 商品名称：商品名称、商品名、商品、产品名称、品名等
- 整件数量：整件数量、整件、整箱数量、件数、箱数等
- 单瓶数量：单瓶数量、单瓶、散瓶、零瓶、瓶数等
- 库存数量：剩余库存、库存数量、当前库存、结存等
- 箱规：箱规、包装规格、规格、每箱数量、每箱瓶数等；没有箱规列时，普通商品行按整件统计，商品名带 `/瓶` 的行按单瓶统计

总数量按 `整件数量 + 单瓶数量 / 箱规` 计算。

出库/退货流水变化按商品行的单位折算到同一口径：出库、出货、补货、夜补、调货、调拨、报损等相关列计为减项；客退等列计为客退增项；多货实退、多货退货等列计为多货退货增项。店铺商品卡片里会额外展示整件出库、单瓶出库、客退整件/单瓶、多货退货整件/单瓶。

## 店铺设置

页面主页会直接展示全部店铺卡片，每个店铺下方展示在售商品、单价、当前日期库存、库存价值、较前日变化、出库拆分和退货拆分；没有在售商品时显示“暂无在售商品”。点击店铺卡片可切换右侧统计范围，点击“全部商品”可取消店铺筛选。店铺区域顶部可导出所有在售商品库存 TXT。每个店铺卡片右上角有“修改”按钮，可在弹窗中修改店铺名称、售卖商品、单价和匹配关键词，或删除店铺。`+` 用于弹窗新增店铺。

每个商品可以设置多个匹配关键词/别名，用逗号分隔。上传数据后，表格里的商品名只要命中商品名称或任意关键词，就会归到该店铺配置的商品名下面。

在“全部商品”模式下，汇总栏的库存价值会按所有店铺配置的商品单价进行匹配，并把所有能匹配到单价的商品价值加总显示。

## 可选服务模式

如果更习惯本地地址访问，也可以在安装了 Python 和 openpyxl 的开发电脑上运行：

```powershell
python server.py
```

然后打开 `http://127.0.0.1:8765`。普通使用和跨平台分发不需要这一步。
